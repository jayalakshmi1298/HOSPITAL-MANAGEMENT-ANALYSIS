Hospital Management Analysis

Project Overview
This project focuses on analyzing hospital operations, patient visits, doctor performance, and financial activities using Excel, SQL, and Power BI.

Tools Used
- Excel
- SQL
- Power BI
- Power Query
- DAX

Data Modelling
- Designed a Star Schema data model.
- Used Fact and Dimension tables.
- Established relationships between hospital datasets.
  
Dashboard Pages
1. Overview
2. Patient and Doctor Analysis
3. Finance and Treatment Analysis

 Key Performance Indicators
- Total Patients
- Total Visits
- Total Revenue
- Insurance Amount
- Patient Payable
- Payment Status

 Key Analysis
- Monthly Visit Trends
- Department Performance
- Doctor Performance
- Patient Ratings
- Revenue Analysis
- Payment Status Analysis

 Project Objective
To transform hospital data into meaningful insights and support data-driven decision-making.
